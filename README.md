# GoldStation V9 — مشروع الذهب

هذا المستودع مُخصّص لتخزين مشروع **GoldStation V9** لحساب مالكه على GitHub.

## محتويات المشروع المطلوب استضافتها
- محرّك التداول متعدد الاستراتيجيات وطبقات SMC وVolume Profile.
- تكامل cTrader Open API على حساب تجريبي (Demo) فقط.
- أدوات البحث والاختبارات واستراتيجيات Pine Script لـTradingView.
- أرشيف بيانات الشموع التاريخية ونتائج الأبحاث.

> **حالة الرفع:** تمت تهيئة المستودع. ملفات الأرشيف الثنائية الأربعة لم ترفع بعد. لا تعتبر هذه الصفحة بديلاً عن نسخة ZIP الكاملة.
