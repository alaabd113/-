## حوكمة مصادر GitHub

- رابط كل مستودع وحالة الفحص في `docs/30_NEW_GITHUB_REPOSITORIES.csv`. بعض المستودعات تعلن نموذج AI أو استراتيجيات تجارية أو تعتمد على MT5 وإضافات لا تتوفر في شموع OHLC الحالية؛ حالتها **لم يُشغّل أصلها**، ولم أنسب لها نتيجة اختبارات التكييف.
- حتى النموذج BOLL+RSI الموجب هو فرضية مستقلة، ليس نسخة أصلية من ملف GitHub محدد.
- لا يوجد تدريب ذكاء اصطناعي جديد ولا تقويم أخبار متكامل؛ لا تتوفر بياناتهم التاريخية للتحقق.
- البدء فقط بمحرك Market Data وShadow ثم حساب ديمو عبر OAuth مع Metadata حقيقية.

## ضوابط مراجعة الكود

1. Compile لجميع الوحدات، وفحوصات Unittest للأوامر الخطرة/الرسائل/الشموع/الإشارات.
2. اختبار عدم تأثير الشموع المستقبلية على الإشارات السابقة، والدخول في الشمعة التالية.
3. اختبار سقوط الصفقة على وقف الخسارة إذا لمست الشمعة الهدف والوقف معاً.
4. عدم السماح بأوامر على حساب حي مهما كانت قيمة `config/settings.json`.
5. عدم إعادة إرسال أمر غير محسوم في SQLite حتى لو تعطل اتصال الشبكة.
6. لا يوجد اختبار End-to-End مع cTrader الحقيقي أو تجريب أوامر ديمو لغياب OAuth وتفاصيل وسيط XAUUSD.
